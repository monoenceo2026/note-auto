# MONOEN note 自動運用（Claudeルーチン）

株式会社モノエンのnote（https://note.com/monoen_co_jp）に、**毎日1本**、
SEO・LLMO・AIO に最適化した記事を**自動で作成・公開**する仕組みです。

- 記事生成：**Claudeサブスク**（このルーチンのセッション）
- アイキャッチ画像：**OpenAI gpt-image-1**
- 公開：**note.com**（あなたの選択により「生成から公開まで完全自動」）
- 差別化：**カニバリ対策 / トレンド分析による根拠あるテーマ選定 / トピッククラスター / 反ありふれ**

---

## 🎯 何をする仕組みか（1日の流れ）

```
毎朝 07:30 JST（≒公開8:00に間に合う時刻）にルーチンが起動
  1. トレンド分析 → 根拠のあるテーマ選定（カニバリ判定つき）
  2. 記事生成（3,000〜5,000字・逆ピラミッド・FAQ・監修・内部リンク）
  3. アイキャッチ生成（gpt-image-1 → note推奨 1280×670）
  4. 公開前QA（景表法/薬機法/未確認事実/カニバリ/ありふれ を自動採点）
       └ 基準未達なら「公開せず下書き＋あなたに警告」に自動ダウングレード（安全網）
  5. note へ自動公開（QA合格時）
  6. 台帳（レジストリ）に追記＝翌日以降のカニバリ制御
  7. Git へコミット＆プッシュ、結果をあなたへ通知
```

> **安全設計**：完全自動公開でも、QAで少しでも不安（法令・未確認の数値/実名・薄い内容）があれば
> **公開せず下書きに落として通知**します。誤情報がそのまま公開される事故を防ぎます。

## ✅ あなたにやってほしいこと（初期セットアップ）

**所要 20〜30分**。詳細は [`SETUP.md`](./SETUP.md) に画面つきで書いています。ここは要点だけ。

| # | やること | 目的 | 必須? |
|---|---|---|---|
| 1 | **OpenAI APIキー**を用意し、この環境のシークレットに `OPENAI_API_KEY` を登録 | アイキャッチ画像生成 | 必須 |
| 2 | **noteのログインCookie**を取得し `NOTE_SESSION_COOKIE` を登録（+ `NOTE_USERNAME=monoen_co_jp`） | 完全自動公開 | 完全自動なら必須 |
| 3 | `PUBLISH_MODE=auto` を設定。**まず `DRY_RUN=1`** で数日テスト | 事故防止の試運転 | 強く推奨 |
| 4 | この環境の**ネットワーク設定**が `api.openai.com` と `note.com` に到達できることを確認 | API通信 | 必須 |
| 5 | 初期1〜2週間は**毎朝の通知を確認**（品質が安定するまでは人の目を残す） | 品質・法令の最終責任 | 推奨 |

> スケジュール（毎朝07:30 JST起動）の登録は**こちらで実施済み/実施します**。あなたの作業は上記だけです。
> テストで問題なければ `DRY_RUN=0` に切り替えると、翌朝から本番の自動公開が始まります。

### 迷ったら（公開の慎重度は3段階で選べます）
- `PUBLISH_MODE=package` … noteには触れず**完成パッケージのみ生成**（最も安全・手動投稿）
- `PUBLISH_MODE=draft` … noteに**下書きまで**自動作成（公開はあなた）
- `PUBLISH_MODE=auto` … QA合格なら**自動公開**（← あなたの選択）

いつでも切り替え可能です。最初の数日は `auto`＋`DRY_RUN=1` で挙動を見ることを勧めます。

## ⚠️ 正直にお伝えするリスク（note自動公開）

noteには**公式の投稿APIがありません**。完全自動公開は、ログインセッションを使う「非公式」な方法で、
**note側の仕様変更で止まること、規約上のリスクがゼロではないこと**を理解の上でご利用ください。
- 本システムは、投稿に失敗しても**必ずローカルに完成パッケージを残し**、手動投稿できるように設計しています（沈黙しません）。
- 不安があれば `PUBLISH_MODE=draft`（下書きまで自動）に落とすのが安全です。詳細は [`OPERATIONS.md`](./OPERATIONS.md)。
